## 🌟 Features

- **Dark Glassmorphism UI**: Crafted with obsidian dark tones (`#09090b`), mesh gradient glows, and backdrop blurs.
- **Interactive CLI Playground (`<CLI Terminal />`)**: A fully functional browser terminal where visitors can type commands (`help`, `about`, `skills`, `projects`, `contact`, `clear`).
- **Filterable Project Showcase**: Instantly sort projects by category (*Web Apps*, *AI Tools*, *Design & Icons*).
- **Live Local Time Machine**: Real-time ticking visitor clock in the hero workspace card.
- **Scroll-Triggered Animations**: Powered by AOS (Animate on Scroll) with smooth reveals and staggered delays.
- **Fully Responsive & Accessible**: Optimized for mobile devices, tablets, and large desktop monitors.

---

## 🛠️ Tech Stack

- **Markup & Styling**: HTML5, Tailwind CSS, Custom CSS (`style.css`)
- **Interactivity**: Vanilla JavaScript (`main.js`)
- **Icons & Visuals**: Lucide Icons, High-contrast SVGs
- **Animations**: AOS (Animate on Scroll library)

## 🚀 Getting Started & Local Setup

To run this project locally on your machine, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/AbderrahmanEMD/Modern-Portfolio.git
   cd Modern-Portfolio
   ```

2. **Open the project:**
   Simply open `index.html` in your favorite web browser, or use a live server extension (like VS Code Live Server).

## 📋 Can People Use This as a Template?

**Yes, absolutely!** 

You are free to use, fork, or adapt this portfolio as a template for your own personal website:
1. **Fork the repository** on GitHub at [AbderrahmanEMD/Modern-Portfolio](https://github.com/AbderrahmanEMD/Modern-Portfolio).
2. Update the personal details, bio, and resume (`assets/Abderrahman_ELMADI_Resume.pdf`) in `index.html`.
3. Replace the project previews in the projects section with your own work.
4. Deploy instantly to **Netlify**, **Vercel**, or **GitHub Pages**.

If you use this template, giving a star ⭐ to the repository is much appreciated!
